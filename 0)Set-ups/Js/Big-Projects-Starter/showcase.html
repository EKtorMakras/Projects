Themes

Three themes from src/scss/settings/_themes.scss. Each one can re-tint a whole palette: dark lightens primary, success and error; sepia uses the Tailwind amber scale as its primary. 

$themes: (
  light: (surface: neutral-50, title: neutral-900, …),
  dark: (primary: hsl(173, 50%, 50%), success: #66bb6a, error: #ef5350, surface: neutral-900, …),
  sepia: (color-scheme: light, primary: map.get(tailwind.$colors, amber), surface: #f4ecd8, …),
);

document.documentElement.dataset.theme = "sepia"; // themeManager.setTheme("sepia")

Palettes

$colors is a list of maps: brand colors as one base color (→ a generated 50–950 scale) and Tailwind hues with their exact values. Every step has a readable -fg color. Switch the theme: the scales change with it. The hex values are read back with getHexColor().

primary (generated; Tailwind amber in sepia)

neutral (Tailwind slate)

@use "@kit/palettes/tailwind" as tailwind; // @kit = @emakras/vanilla-kit/scss

$brand: (primary: hsl(173, 58%, 39%), secondary: hsl(10, 58%, 39%));
$extras: (neutral: map.get(tailwind.$colors, slate), info: map.get(tailwind.$colors, sky));
$palette: ($brand, $extras); // merged in order, duplicates are an error

Status colors

success, warning, error and info are palettes too: --clr-success-50…950 with -fg colors. Here info is replaced by Tailwind sky, and the dark theme lightens success and error.

Forms

Every native control gets the kit's look in project/base/_forms.scss. They stay real inputs, follow the theme and keep keyboard focus. 

input:not([type="checkbox"], [type="radio"]), textarea { @include kit.field($focus-color: primary); }
select { @include kit.select($focus-color: primary); }
input[type="checkbox"]:not([role="switch"]) { @include kit.checkbox($color: primary); }
input[type="radio"] { @include kit.radio($color: primary); }
input[role="switch"] { @include kit.switch($color: primary); }

Animations

kit.keyframes emits the @keyframes once (project/base/_animations.scss); kit.animate(name) plays one, timed with the kit's duration and easing tokens. spin and pulse loop; the others play once. They stop for users who prefer reduced motion. 

@include kit.keyframes; // once, at the root

.toast { @include kit.animate(slide-up); }
.loader { @include kit.animate(spin); } // 1s linear infinite
.field--invalid { @include kit.animate(shake, $duration: kit.duration(slow)); }

Social icons

Official colors always (top) or on hover only (bottom, like the footer).

.instagram { @include kit.social-icon(instagram, lg, $official: true); }
